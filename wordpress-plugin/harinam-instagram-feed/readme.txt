Harinam Instagram Feed 1.0.1

Requires the Instagram Feed plugin by Smash Balloon and a connected public
@harinamjoli account. Connect the account in Instagram Feed settings first.

Provides GET /wp-json/harinam/v1/instagram for the storefront. Returns public
photos, carousel images and videos/reels, including reels outside the main
profile grid. Access tokens and pagination URLs remain on the server.

The endpoint does not create, edit or delete Instagram content.
Confirm the connected account and verify the live feed after activation.
